# Folder Kredensial

Folder ini digunakan untuk menyimpan file kredensial Firebase:
- `firebase-key.json`

> **PERINGATAN KEAMANAN**:
> File kredensial asli (`firebase-key.json`) **tidak boleh di-upload** ke GitHub atau repository publik.
> Gunakan contoh template pada `firebase-key.example.json` sebagai acuan saat mengonfigurasi di environment lokal / server baru.
